# UX Designer, Globex

Globex makes software for small shops. We need a UX designer to own the
checkout and the account pages.

What you do:

- Plan and run user research with shop owners.
- Make flows, wireframes and prototypes in Figma.
- Work with the engineers to ship each change.

What you bring:

- Three or more examples of product design work.
- Experience with a design system.

This job is remote. Apply at jobs.example.com.
