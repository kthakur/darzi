# Design Technologist, Initech

Initech builds tools for office teams. The design technologist turns designs
into working prototypes and helps the team keep one component library.

Tasks:

- Build prototypes in React from Figma files.
- Keep the component library and its documentation up to date.
- Test new ideas with users and report the results.

Requirements:

- Good knowledge of HTML, CSS and JavaScript.
- Two days each week in the office.
